Create a virtual environment for this repo:
python3 -m venv .venv

Activate it:
source .venv/bin/activate

You should see:
(.venv) ➜ python-engineering-playbook

Install dependency
python -m pip install psutil

verify:
python -c "import psutil; print(psutil.__version__)"

Then add .venv to .gitignore:
echo ".venv/" >> .gitignore


Add dependeny to requirements.txt:
pip freeze | grep requests >> requirements.txt
